# 工程确认记录与历史范围

记录日期：2026-10-05；仓库整理日期：2026-10-06。技术事实来自项目负责人确认及厂商资料核对。原始需求往来、私人说明和识别中间文件仅在本地及受限协作资料中留存。

## 现行方案

地面 F407 使用 USART3 PB10/PB11 接 F103、USART2 PA2/PA3 接 Zynq PS UART0 MIO14/MIO15，外部接点为 Explorer P2/P4 和 Navigator P5。先以 115200 验证，再统一复测 460800。拆 P5 两只 PS/USB 跳帽、隔离 P2/P4 串口选择和 P1 音频支路、停用 ETH/音频、将 UART0 日志迁至 RAM，均是接线方案的组成部分。方案确认不代表实物已连接或已测量。

| 项目 | 已确认技术事实 | 验证边界 |
| --- | --- | --- |
| 地面 F103 | 最小系统板，外部晶振 8 MHz | 软件沿用 STM32F103C8T6，完整丝印及焊接选项由上板操作者核对 |
| 机载 E07 | 尚未接线 | 已有基于 Explorer V3.4 的建议 AIR 配置，READY 保持 0 |
| Zynq | 采用 7020，使用领航者 V2 资料盘 | 厂商标准型号为 XC7Z020-2CLG400I；实物完整丝印、底板修订与电压仍应登记 |
| 视频分工 | 摄像头连接 FPGA；F407 汇总两路信息，后续可作小规模计算 | 当前仅提供模拟视频状态；视频采集、角度计算和 YOLO 尚未完成实板验收 |
| 无线分工 | F103 处理无线桥接；机载 F407 为 E07 测试端 | 返回模拟遥测，不包含 IMU/PID/DShot 或真实飞控 |
| 工具链 | CubeMX 已安装并完成实际版本、生成及构建核查 | 生成基底与完整手动 HAL 通信工程分开，见工具链及迁移记录 |

资料盘包含 V3.9 底板图，也有标为 V3.7 的旧音频版本和 7010/7020 示例。已核对的 V3.6/V3.9 串口路线一致；目录名称不能独立证明实际底板版本。底板 V3.8 音频变更、V3.9 丝印调整和核心 V2.5/V2.4 接口兼容性来自厂商记录，不代替实物电源和引脚核对。

## 历史路线与判断限制

早期路线为 F407 USART6 PC6/PC7 接 UART1 EMIO，J4.3/U5 RX、J4.4/T5 TX。该路线的 HDF、布局布线和 SDK 记录均属于历史证据，不能直接证明当前 UART0 MIO 方案通过。旧证据的页码、哈希和变更范围见[硬件证据](hardware_evidence.md)、[底板查证](zynq_navigator_v2_evidence.md)和[7020 厂商资料](zynq_7020_vendor_lookup.md)。

早期需求中关于额外链路数量的描述不足以形成明确接口约束，因此未据此增加线路；技术实施仅采用已确认的通信拓扑。当前完整结果见[UART/MIO 迁移记录](progress_uart_mio_migration.md)，操作与验收见[联调步骤](bring_up.md)。PC 测试、编译链接、物理通信、视频采集及飞控必须分别记录。
